# 人物大厅

首页右上角的搜索按钮打开人物大厅。大厅支持按名称、简介、人设和作者搜索；分类根据公开文本中的关键词筛选，并非来源平台的原始标签。点击卡片可查看介绍和开场白，再开始聊天。首页推荐流也会随机展示目录人物。

人物目录和已有聊天角色分开。第一次开始聊天时才创建角色和会话；再次进入同一来源人物会打开原会话，不会覆盖已有聊天或编辑。来源没有公开完整人设时，详情页会提示聊天使用公开简介作为背景。

## 预置人物和构建

预置目录位于 `app/src/main/assets/catalog/`，包含 `characters.json` 和 `images/<来源 ID>/` 下的封面、立绘。Android 构建直接将该目录打包进 APK，不依赖项目根目录的 `charactorSample/`。原始样本仍保存在被 Git 忽略的本地目录。

更新预置目录后重新构建并安装 APK 即可更新人物；已有聊天和用户修改不会被目录更新覆盖。请确认有权使用和分发所打包的人物文字和图片。

## 人物音色

应用加载目录时会按来源 ID 保存音色匹配结果；已进入聊天的人物与目录共用该设置。匹配器只使用明确属于人物的性别和年龄，信息不足时标记待选择。打开角色主页并进入编辑页，可在「角色音色」中手动选择或恢复自动匹配，选择立即保存，不会被之后的目录导入覆盖。

聊天朗读和语音通话优先使用人物音色；首选失败时，仅在存在同类备选时尝试备选。没有已确认音色时可使用用户明确设置的全局音色。普通聊天朗读在这些音色不可用时会尝试系统语音；语音通话则提示并停止播放。火山音色权限与服务故障也可能导致无法播放；音色名称体现的年龄感只是近似，选择前可在火山控制台试听。手机聊天语音条仍使用 Android 系统 TTS。

首页开场白在人物或全局音色不可用、云端合成失败时，改用设备的系统文字转语音引擎，并提示当前使用系统语音；这不会修改人物音色设置。若系统引擎也不可用，首页仍会展示开场白与介绍。
