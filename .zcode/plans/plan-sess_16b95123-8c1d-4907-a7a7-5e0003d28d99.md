# 心声升级:短文+配图 + 全屏详情页(飞入拼图/打字机/翻转信纸/TTS/BGM/封面参照生图)

## Context

现状:每条心声只有 `title(≤12字)+ echo(≤40字) + 可选配图`,在半屏弹层里平铺列表,**没有详情页**;生图是纯文生图(不参照人物封面)。目标对齐参考截图(猫箱):心声 = 第一人称短文 + 配图,点击进入全屏详情页 —— 三段图飞入拼合 → 拍立得+标题打字机 → 翻转信纸显示全文+TTS 朗读+背景音乐,底部 下载/重新生成/设为聊天背景 三按钮(用户已确认全做);生图参照人物封面形象(i2i)。BGM 仅详情页播(已确认);TTS 翻到信纸自动朗读、可打断(已确认)。

## 1. 数据模型:心声加正文短文

- `data/InnerVoiceEntity.kt`:加 `content: String = ""`(第一人称短文,≤300字,段间 `\n\n`)。`title`=信纸标题、`echo`=拍立得下方签名句(语义不变)。
- `data/GouXiangDatabase.kt`:version 13→14,新增 `MIGRATION_13_14`:`ALTER TABLE inner_voices ADD COLUMN content TEXT NOT NULL DEFAULT ''`。旧数据 content 空 → 详情信纸正文回落 echo,完全兼容。

## 2. 生成链:产出短文

`chat/InnerVoiceGenerator.kt`:
- `Draft` 加 `content`;常量 `CONTENT_MAX_CHARS = 300`。
- systemPrompt 输出协议改为 `{"voices":[{"title":…,"echo":…,"content":"150~250字短文,2~4段,段间用\n\n分隔"}]}`,规则里加:content 是完整的第一人称内心独白短文(有细节、有情绪起伏,可引用记忆事件);echo 是配图下的一句话签名。
- `parse()` clamp content(缺失 → "",兼容旧形态);`toEntities()` 落 content。

`work/DerivativeExecutor.kt` `executeInnerVoice()`(~L112):
- 生图 prompt 改为:`"${character.appearance}。保持参考图中人物的样貌、发型与穿搭,画面:${voice.title},${voice.content.take(80)}。${character.appearanceStyle},柔和电影感光影,情绪特写,竖版构图"`,并传封面参考文件。

## 3. 生图参照封面(i2i)

`ai/image/` 三文件:
- `ImageGenAdapter.kt`:`ImageGenRequest` 加 `referenceImage: String? = null`(data URL)。
- `OpenAiCompatibleImageGenAdapter.kt`:构造参数加 `referenceAsArray: Boolean = false`;`buildRequestBody` 在有参考图时发 `"image"` 字段 —— 火山 Ark seedream 发 JSON 数组形式(`"image":["data:image/jpeg;base64,…"]`,已查证官方格式),硅基 Kolors 发字符串形式(其 /images/generations 支持 base64 data URI)。
- `AvatarImageProvider.kt`:`getOrGenerateInnerVoiceImage(characterKey, prompt, referenceImage: File?)` —— 参考文件存在则读字节→base64 data URL 传入;为 null/读失败 → 纯文生图(现行为兜底)。ark 适配器 `referenceAsArray=true`,硅基 false。
- DerivativeExecutor 侧解析封面路径:`character.avatarFile` 非空 → `File(File(app.filesDir, "avatars"), character.avatarFile)`。

## 4. 详情页 UI

新文件 `ui/innervoice/InnerVoiceDetail.kt`(全屏覆盖层)+ 改 `ui/innervoice/InnerVoiceScreen.kt`:

**列表卡改造**:VoiceCard 正文行显示 content 预览(maxLines=3,空回落 echo),整卡可点击 → 打开详情;删除/重试按钮保持自身可点。Screen 根布局 Column→Box 包裹,详情作为最上层子 Box(局部 `remember` state),BackHandler 先关详情再关弹层。需要 characterName(state 已有)。

**详情页结构**(对照截图):
- 近黑背景 + 顶部左返回箭头;中间翻转卡容器;底部按钮行。
- **三段飞入**(图1):imageFile 有图时,进入详情先播 3 条横向切片(各 1/3 高、`clipToBounds`,内部放整图 offset `-i*sliceHeight`),translationX 依次 `-W→0 / +W→0 / -W→0`(左/右/左),tween≈450ms、delay 0/160/320ms;播完 Crossfade 成整图。每条心声只在首次进入时播,翻转返回不重播。无图 → 跳过动画画 💗 占位。
- **拍立得**(图2):白框圆角卡,图区 3:4;图上左上「AI 生成」角标、左下喇叭圆钮(TTS 重播/停止)、右下「查看心声」胶囊钮(触发翻转);图下方 echo 打字机逐字显示(≈110ms/字,空回落 title)+ 右下作者名(characterName)。
- **翻转**(图3):`Animatable` 0→1 驱动 rotationY + cameraDistance 加大,90° 处换内容,背面预置 rotationY=180 校正镜像;点信纸卡翻回图片。
- **信纸**:米白纸卡(径向渐变模拟同心圆纹),标题 title + 正文 content(空回落 echo)+ 右下大号作者名 + 底部「由 AI 生成」水印。
- **底部按钮行**:① 下载图标钮(MediaStore.Images → Pictures/GouXiang,minSdk 29 无需权限,Toast 结果)②「重新生成」灰胶囊(= 删该条复用 `deleteInnerVoice` + 入队新一批 `generateInnerVoices()`,详情页自动回列表;新卡出现在列表顶部)③「设为聊天背景」黄胶囊(复用 `ChatBackgroundPrefs.setBackground`,无图禁用)。

## 不做 / 边界

- 重新生成 = 换一批新心声(批量管线决定),不做单条文字原位重写。
- BGM 无 audio focus 处理(工程无先例,前台短时播放);媒体音量随系统。
- 若真机无豆包语音 key,TTS 自动回落系统 TTS(既有链路)。
